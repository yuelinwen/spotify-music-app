# Spotify Music App Preview

A music listening App, build with Angular & NodeJS

Browsing, searching and 30-second previews need no account. Register one only
to save favourites — or try username: abc, password: 123456

Track data and previews come from the iTunes Search API; the charts on the
home page come from Apple's music feed, proxied by the
[user API](https://github.com/yuelinwen/spotify-music-app-backend) because
that feed sends no CORS header. Previews are provided courtesy of iTunes.
